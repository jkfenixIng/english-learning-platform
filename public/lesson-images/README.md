# Lesson images

- Level heroes: `level-a1.png` → `level-c2.png` (pollinations/flux, 1024×576) — thematic per CEFR: A1 greetings, A2 daily life, B1 travel, B2 work, C1 academic, C2 business.
- Teaching placeholder: `teaching-placeholder.png` — fallback for `TeachingContent` when no blocks/cover or when `onError` fires (picsum failure or missing local).
- Unit/lesson thematic images: `lessons/a1-u2-l1.png`, `a1-u3-l1.png`, `a1-u4-l1.png`, `b1-u1-l1.png`, `b2-u1-l1.png`, `c1-u1-l1.png`, `c2-u1-l1.png` (flux 1024×576) — contextual per unit/lesson (greetings, family, food, professional meeting, campus, academic conference, boardroom). Other lessons reuse `teaching-placeholder.png` via client-side `onError` fallback to avoid broken images.
- Exercise flashcards: `exercises/flashcard-apple.png`, `flashcard-sustainable.png`, `flashcard-mitigate.png` — local Pollinations assets for top vocab (apple, sustainable, mitigate). New `prisma/seed.ts` prioritizes local `/lesson-images/exercises/flashcard-{word}.png` and falls back to `picsum.photos` only if local missing; Renderer shows `teaching-placeholder.png` on error and uses rich `alt` (`front + context`).
- Content enrichment (Fix-11-A): `prisma/seed.ts` now generates 6 units × 5 lessons per level = 30 teach/quiz + 1-2 exams per level → 188 lessons total (was 42). `buildLessonContent()` creates 9 blocks per teach lesson: heading, 2 paragraphs (intro + grammar), 1 image with thematic `altEs/captionEs`, 3-4 vocab (word/definition/definitionEs + example), 2 examples, 1 list (key phrases), 1 callout tip. Vocab varies per unit (no longer just goal/practice). All blocks are bilingual `text/textEs` and rendered via `lib/lesson/localize.ts` (`localizeBlock`).
- Exercise hero images: `graded_reading`, `comprehension`, `matching`, `flashcard` now always include `imageUrl` (local placeholder or level hero) so Renderer hero never renders empty; `FlashcardRenderer`, `GradedReadingRenderer`, `ComprehensionRenderer`, `MatchingRenderer` all have `onError` → placeholder and improved `alt`.
- Validation: `lib/validation/admin.ts` now accepts local paths (`/lesson-images/...`) as valid `coverImage`/`assets.images[].url` via `localOrHttpUrl` and validates `alt` length.
- Fallback chain: local `/lesson-images/*` → placeholder `teaching-placeholder.png` → `picsum.photos` only as last resort for flashcards. Remote patterns in `next.config.ts` allow picsum/unsplash/supabase.
- Generated via `pollinations_generateImage` (flux, enhance:true). Re-generate with `npx tsx` or manual pollinations call if needed. Free tier: ~9 images generated in Fix-11-A (3 flashcards + 6 lessons).
